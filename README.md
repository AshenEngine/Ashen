# Ashen

**Ashen** is a pure-Rust game engine built for performance, modularity, and an intuitive developer experience.

> **Status:** Early Development - Building the core foundations.
> *Contributions, ideas, and feedback are welcome!*

## Vision

Ashen bridges the gap between low-level performance and developer accessibility by combining:

- **Data-Oriented ECS Core:** High-performance, flexible architecture driven by modern Entity Component System principles.
- **Intuitive Visual Editor:** Designed with a zero-friction UX so new users can jump in and start creating immediately.
- **Extreme Modularity:** Decoupled architecture where major subsystems (Physics, Input, Audio) are fully optional.
- **Unified Rendering Pipeline:** Focused, streamlined graphics and asset pipelines designed to eliminate redundant rendering paths.
